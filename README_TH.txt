Trade Memo Private V10

## สิ่งที่เพิ่มใน V10
- แสดงวันที่และเวลาเข้า Order กับวันที่และเวลาปิด Order แยกจากกันอย่างชัดเจนในหน้า Diary, หน้าสรุปผล, หน้าตรวจสอบก่อน Import จาก CSV/Excel และ Gemini รวมถึงหน้าแก้ไข Order
- วันที่/เวลาที่แสดงเป็นเวลาไทยหลังปรับ offset ตาม Settings (ค่าเริ่มต้น +7 ชั่วโมง) และวันที่จะเปลี่ยนตามอัตโนมัติหากการบวกเวลาเลยเที่ยงคืน
- Gemini prompt/schema รองรับ entryDate/exitDate และวันเวลาเต็ม entryAt/exitAt เพื่อดึงวันที่จากภาพได้ดีขึ้น
- CSV/Excel รองรับคอลัมน์วันแยกและ datetime รวมถึง opening_time_utc / closing_time_utc และชื่อที่พบบ่อยอื่น ๆ
- หากต้นฉบับไม่ได้มีวันที่จริง ระบบจะแสดงข้อความ “ไม่พบวันที่ในต้นฉบับ” แทนการแสดงวันที่ fallback เสมือนว่าถูกอ่านมาจากแหล่งข้อมูล ทั้งนี้วันลงไดอารี่ยังใช้สำหรับจัดเก็บออเดอร์ที่ไม่มีวันที่ให้ได้
- ข้อมูลออเดอร์เก่ายังคงใช้ได้โดยไม่ต้อง Import ใหม่; วันที่ที่มีใน record เดิมจะแสดงได้ตามปกติ

## ตัวอย่าง
CSV ต้นฉบับ: opening_time_utc = 2026-09-15T15:05:01, closing_time_utc = 2026-09-17T02:10:00
เมื่อปรับเวลา +7 จะเห็น:
- เข้า: 2026-09-15 22:05:01
- ออก: 2026-09-17 09:10:00

## MFE / MAE — ยังไม่คำนวณใน V10
MFE (Maximum Favorable Excursion) คือระยะที่ราคาวิ่งไปทางที่เป็นประโยชน์ต่อสถานะมากที่สุดระหว่างเข้าและออก ส่วน MAE (Maximum Adverse Excursion) คือระยะที่ราคาเคลื่อนไหวสวนทางมากที่สุดในช่วงเดียวกัน การคำนวณต้องมีราคาตลาดระหว่างเวลาเข้าและออก ไม่สามารถคำนวณจากราคาเข้า/ออกกับกำไรสุทธิอย่างเดียวได้

แหล่งข้อมูลที่แนะนำคือประวัติราคา M1 หรือ Tick ของ Symbol เดียวกันจากโบรกเกอร์/เซิร์ฟเวอร์เดียวกับที่เทรด ใน MT5 ไปที่ Market Watch → คลิกขวา Symbols → เลือก Symbol → แท็บ Bars หรือ Ticks → Request → Export เป็น CSV หากต้องการคำนวณ MFE/MAE รายออเดอร์ ต้องจับคู่ข้อมูลราคาในช่วงตั้งแต่เวลาเข้าไปจนถึงเวลาออกของแต่ละ Position ด้วย M1 ให้ค่าประมาณตามความละเอียดแท่ง ส่วน Tick จะละเอียดกว่าแต่ข้อมูลมีขนาดใหญ่กว่า

แนวทางสำหรับรุ่นถัดไปคือเพิ่มตัว Import ไฟล์ผล MFE/MAE จาก MT5 แล้วจับคู่ Order ด้วย Ticket/Position ID หรือสร้าง MQL5 exporter เพื่อคำนวณ MFE/MAE และส่ง CSV กลับเข้า TradeMemo สำหรับแสดง MFE, MAE, Pips, ระยะราคาที่วิ่งสวนทาง/ไปทางกำไร และสถิติ TP/SL จากประวัติจริง ทั้งนี้ MFE/MAE เป็นข้อมูลย้อนหลัง ไม่ใช่การรับประกันระยะที่ตลาดจะวิ่งในอนาคต

## ฟังก์ชันเดิมที่คงไว้
- Gemini AI สำหรับอ่านภาพ MT5 หลายภาพ
- Import CSV/Excel พร้อมปรับเวลาอัตโนมัติ
- Google Drive Sync ระหว่าง iPhone/iMac แบบ merge Order
- แยกพอร์ต Standard / Cent
- เรียง Order ตามวันและเวลาเข้า
- ราคาเข้า/ออกเก็บทศนิยมสูงสุด 3 ตำแหน่ง
- สถิติ Δ ราคา/Pips และสถิติตามช่วงเวลาเข้าเทรด

## ติดตั้ง
นำไฟล์ทั้ง 5 ไฟล์ใน ZIP ไปแทนชุดเดิมบน GitHub Pages: index.html, guide.html, README_TH.txt, manifest.json และ sw.js จากนั้น Reload/เปิดเว็บใหม่บนทั้ง iMac และ iPhone ให้โหลด Service Worker V10


## Partial Close / Position-level stats ใน V10
- รองรับรวมส่วนปิดย่อยของ Position เดียวกันเมื่อมี Position ID เดียวกัน หรือ ticket/ข้อมูลเข้า Position ตรงกัน
- CSV/Excel รองรับ `position_id` / `Position ID`, `lots` (Lot ที่ปิดในรายการนั้น) และ `original_position_size` (Lot เริ่มต้นของ Position). Gemini schema และแบบฟอร์มกรอกเองก็มีช่อง Position ID และ Lot เริ่มต้น
- Diary แสดงรายละเอียด Partial Close ในรายการขยายดูได้ รวมถึงวัน/เวลาปิดจริง, Lot ปิด, ราคาปิด, P&L สุทธิของส่วนนั้น, เปอร์เซ็นต์ที่ปิดสะสม, Overnight และส่วนที่ทำให้ Position ปิดครบ 100%
- P&L รายวันยังลงตามวันที่ปิดแต่ละส่วนจริง; Win/Loss, Win rate, Profit Factor, Expectancy, R:R, streak และ Max Drawdown คำนวณจาก Position ที่ปิดครบแล้ว โดยรวมผลของทุก partial close ของ Position เดียวกันเป็นหนึ่งไม้
- หากข้อมูลไม่ระบุ Position ID / ขนาด Lot เริ่มต้นและ Ticket ไม่ตรงกัน อาจรวมรายการไม่ถูกต้องได้ กรุณาตรวจ Preview ก่อนบันทึก

## Google Drive Sync เร็วขึ้น
- การส่งรูปที่ยังไม่มีบน Drive ใช้ concurrency สูงสุด 3 ไฟล์; การดาวน์โหลดรูปที่ขาดในเครื่องก็ใช้สูงสุด 3 ไฟล์เช่นกัน
- จำกัดไว้ที่ 3 เพื่อเร่งการซิงค์ครั้งแรกโดยไม่ยิงคำขอจำนวนมากเกินไปพร้อมกัน. หากภาพบางรายการส่งไม่สำเร็จ Sync จะแจ้งจำนวนที่มีปัญหา และกด Sync อีกครั้งเพื่อ retry ได้
- ไฟล์ข้อมูลหลักยังรวมข้อมูลก่อนอัปโหลด และไม่ได้เปลี่ยนวิธี merge Order. แนะนำให้ใช้ Sync ให้เสร็จทั้งสองอุปกรณ์ก่อนแก้ข้อมูลซ้ำของ Position เดียวกันพร้อมกัน


## ปรับปรุงหน้าจอและ Partial Close ใน V10
- สำหรับ Position ที่แบ่งปิด: แสดงราคาเข้า/ออก, Δ ราคา, Pips, P&L และโน้ตของแต่ละส่วนปิดในรายละเอียดเดียวกัน
- สรุปในกลุ่ม Partial Close: แสดง Δ ราคา/Pips ดีที่สุด, แย่ที่สุด และค่าเฉลี่ยจากส่วนปิดที่มีราคาเข้าและออกครบ
- เพิ่ม “เหตุผล / อารมณ์ของ Position” และ “โน้ตของส่วนปิดนี้”; โน้ต Position จะแสดงบนการ์ดใน Diary และโน้ตของแต่ละส่วนปิดจะแสดงในตารางรายละเอียด โดยไม่ต้องเปิดหน้าต่างแก้ไข
- รูปหน้าจอ MT5 เก่าที่ยังบันทึกในหมวด mt5 จะถูกรวมแสดงกับ “รูปประกอบสรุปหลังเทรด” โดยไม่ต้องอัปโหลดใหม่; รูปที่เพิ่มจากพื้นที่รวมจะบันทึกในหมวดสรุปหลังเทรด
- ซ่อนป้ายที่ไม่จำเป็นสำหรับ Order ที่เปิดและปิดในวันเดียวกัน; แสดง Overnight เฉพาะเมื่อถือข้ามวัน
- ตัดคำอธิบายซ้ำในหน้าต่างแก้ไขและหน้าสรุปออก ปรับ typography ให้มีลำดับขนาดที่สม่ำเสมอ ใช้ line icons แทนอีโมจิ และเปลี่ยนตัวเลือกอารมณ์เป็น Awesome / Good / Normal / Upset / Ruined
- เปลี่ยน Service Worker cache เป็น V10; หลังอัปโหลดต้อง Reload ทั้ง iMac และ iPhone

## ข้อควรทราบเรื่อง Position Note
โน้ต Position ที่บันทึกใน V10 จะถูกเก็บเป็นฟิลด์แยกและซิงค์ไปกับข้อมูล Order. หากแก้โน้ตของ Position ที่มี Position ID เดียวกัน โน้ตหลักจะถูกอัปเดตให้กับทุกส่วนปิดของ Position นั้น ส่วน “โน้ตของส่วนปิดนี้” คงแยกกันเป็นรายส่วน
