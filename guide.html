📓 Trade Memo Private

หลักการ: Journal ใช้งานแบบ local-first ข้อมูลหลักอยู่ใน IndexedDB ของ browser. Google Drive, Claude และ Gemini เป็น optional integrations.

1. เปิดบนเครื่อง

ต้องเปิดผ่าน http:// หรือ https:// ไม่ควรเปิด file:// หากต้องการ PWA, IndexedDB, OAuth หรือ Service Worker

ในโฟลเดอร์นี้รัน python3 -m http.server 8765 แล้วเปิด http://localhost:8765

2. หน้าใช้งาน

  • ไดอารี่: เลือกวัน, week strip, แผนก่อนเทรด, รูปกราฟ, ออเดอร์, screenshot MT5, review
  • สรุปผล: day/week/month/year/all, P&L, Winrate, Profit Factor, Expectancy, R:R, Drawdown, streak, equity curve, bar chart, calendar และ breakdown
  • ตั้งค่า: theme, currency, starting balance, Google Drive, Claude/Gemini keys, backup/import

3. Backup

กดสำรองข้อมูลเป็น JSON ไฟล์เดียว (รวมรูปเป็น Base64) แล้วเก็บไว้ใน Google Drive หรือ OneDrive ของคุณเอง

4. Google Drive

สร้าง Google Cloud project → เปิด Drive API → OAuth consent → เพิ่มตัวเองเป็น Test user → สร้าง OAuth Web client → Authorized JavaScript origin ให้ตรงกับ URL ที่ใช้จริง → วาง Client ID ใน Settings

5. ความปลอดภัย

อย่าเก็บ MT5 password, broker password, API secret, private key หรือ seed phrase. AI screenshot จะถูกส่งไป Anthropic หรือ Google เฉพาะเมื่อคุณกดใช้บริการนั้น.

6. ข้อจำกัดของเวอร์ชันนี้

OCR local ปุ่มถูกเตรียมไว้ แต่ยังไม่มีการฝัง Tesseract.js ลงมา เพื่อให้เวอร์ชันฐานไม่มี dependency เพิ่มโดยอัตโนมัติ. คุณสามารถใช้เพิ่ม trade แบบ manual หรือ Claude/Gemini ได้ทันทีเมื่อใส่ key.
