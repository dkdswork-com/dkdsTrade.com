📓 Trade Memo Private v6

หลักการ: Journal ใช้งานแบบ local-first ข้อมูลหลักอยู่ใน IndexedDB ของ browser. Google Drive, Gemini และ Excel reader เป็น optional integrations.

1. นำเข้า Order หลายรายการ

ในหน้า Diary กด 📥 อ่านจาก MT5 แล้วเลือกได้ 3 แบบ:

  • 📷 เลือกภาพหลายภาพ — ส่งภาพเป็นชุดให้ Gemini อ่าน และรวมผลให้ตรวจสอบก่อนบันทึก
  • 🗂️ CSV — อ่านไฟล์ข้อความโดยรองรับ comma / semicolon / tab
  • 📊 Excel — อ่านไฟล์ .xlsx จาก Sheet แรก

2. การเรียง Order

Order ในหน้า Diary จะเรียงตาม วัน-เวลาเข้าออเดอร์จากเก่า → ใหม่ อัตโนมัติ ไม่ว่าจะเพิ่มพร้อมกันหลายไม้หรือเพิ่มทีละรอบ เพื่อให้เห็นลำดับการเข้าไม้ต่อเนื่องกัน.

3. ราคาเข้า/ออก

ราคาเข้าและราคาออกจะถูก ตัด ทศนิยมส่วนที่เกินออก เหลือ 3 ตำแหน่ง เช่น 2654.98765 → 2654.987 โดยไม่ปัดขึ้น.

4. การปรับเวลา

ค่าเริ่มต้นคือ +7 ชั่วโมง จากเวลา MT5 ไปเป็นเวลาไทย. ระบบปรับทั้งวันที่และเวลา ตอนนำเข้า/บันทึก Order. เช่น 2026.09.18 20:30:00 จะเป็น 2026-09-19 03:30:00.

เปลี่ยนค่าได้ที่ ตั้งค่า → ปรับเวลาจาก MT5 → เวลาไทย.

5. การ Preview

ก่อนบันทึก ระบบจะแสดงวันที่, Symbol, Side, Lot, เวลาเข้า/ออก, P&L และ Ticket. คุณสามารถเอาเครื่องหมายถูกออกจากรายการที่ไม่ต้องการบันทึกได้.

6. CSV/Excel

ระบบจับคู่ชื่อคอลัมน์ที่พบบ่อย เช่น:

ข้อมูลตัวอย่างชื่อคอลัมน์
SymbolSymbol, Asset, Instrument
ฝั่งType, Side, Direction
LotVolume, Lot, Lots
เวลาเข้าOpen Time, Entry Time
เวลาออกClose Time, Exit Time
ราคาOpen Price, Close Price, Entry Price, Exit Price
ผลลัพธ์Profit, P&L, Net Profit
ต้นทุนCommission, Swap
อ้างอิงTicket, Position, Order ID

แนะนำให้ 1 แถว = 1 Order ที่ต้องการบันทึก. ถ้า Export ของ MT5 แยก Open/Close เป็นคนละ Deal row และต้องจับคู่กันเอง โครงสร้างนั้นอาจต้องจัดเป็นไฟล์สรุปก่อน.

7. Standard / Cent

Symbol ที่ลงท้ายด้วยตัว c จะถูกเก็บเป็น Cent เช่น XAUUSDc และ Dashboard/Diary จะแยกผลกับ Standard ต่อไป.

8. เปิดใช้บนเครื่อง

รัน python3 -m http.server 8765 แล้วเปิด http://localhost:8765. สำหรับ GitHub Pages ให้อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้.

9. ความเป็นส่วนตัว

ข้อมูลหลักอยู่ใน IndexedDB ของ browser. CSV/Excel ถูกอ่านใน browser. ภาพจะถูกส่งไป Gemini เฉพาะเมื่อคุณกดใช้ AI. อย่าเก็บ password, private key หรือ seed phrase.

Excel: ตัวอ่าน .xlsx โหลด SheetJS จาก CDN เมื่อกดนำเข้า Excel ดังนั้นครั้งแรกที่ใช้งาน Excel ต้องต่ออินเทอร์เน็ต.
